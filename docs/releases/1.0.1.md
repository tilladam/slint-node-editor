# Slint Node Editor 1.0.1

Documentation-only patch for the first stable release. The library API and
Rust/Slint implementation are unchanged from 1.0.0.

- Fix the demo link in the README published on crates.io and docs.rs.
- Use versioned screenshot URLs and the verified [demo video](https://github.com/tilladam/slint-node-editor/releases/download/v1.0.0/demo.mp4).
- Remove pre-publication setup instructions from the packaged documentation.

```toml
slint-node-editor = "1.0.1"
```

Requires Slint 1.18.0 or newer and Rust 1.92 or newer. The setup, migration notes,
and known limitations in the [1.0.0 release](https://github.com/tilladam/slint-node-editor/releases/tag/v1.0.0)
continue to apply.
